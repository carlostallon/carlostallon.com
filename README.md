# carlostallon.com

Personal portfolio website showcasing design work at the intersection of design, technology, and business.

## Features

- Clean, minimalist design
- Interactive portfolio carousel
- Fully accessible (ARIA labels, keyboard navigation)
- Responsive design with dark mode support
- SEO optimized (Open Graph, JSON-LD)
- Performance optimized (lazy loading, preload)
- Motion sensitivity support

## Tech Stack

- Vanilla HTML/CSS/JavaScript
- No frameworks or dependencies
- Inter font family
- CSS variables for theming

## Structure

- `index.html` — Portfolio homepage
- `css/`, `js/`, `img/` — Site assets
- `box44/` — Weekly training calendar (private utility page)

## Deployment

Automatically deployed to DreamHost via GitHub Actions on push to the `master` branch.
